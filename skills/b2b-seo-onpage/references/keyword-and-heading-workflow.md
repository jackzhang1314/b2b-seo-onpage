# 已选关键词：从页面目标到可用改稿

只读本次涉及的部分。以下是编辑判断方法，不是固定排名公式。

## 一页一份目标

记录目标 URL/稿件、已选主词、相容辅词、页面职责、采购任务和内容语言。选词来自用户、已确认架构或布局决定；不根据需求表第一行、最高量词或型号的泛属性自动换主词。

已有架构时复用该页模块顺序及独有内容。因页面实际内容变化需要调整模块，可以提出具体理由；若涉及页型、URL、父子层级或模板，列成架构修订建议，不把单页优化扩成新一套架构。

完整优化先完成[行业词库、SERP与竞品研究](research-workflow.md)，再看页型适配、内容缺口和采购任务。辅助词来自研究取舍；现有正文/规格可补充编辑候选，标明来源、不赋予搜索量，不能代替必需的行业词库。小修改保留有效部分并复用已有研究。

## SEO 标题（Title）与摘要

按[Title 与摘要方法](title-and-snippet.md)选择本页对象、采购任务和可兑现的点击理由，输出一个推荐版本及依据。该文件包含不同页型、品牌/型号位置、承诺校验、长度预览、Google 改写诊断和效果观察；局部任务只读相关部分。标题、H1 与实际正文必须承接同一任务。

## H1–H6 与正文结构

先列真实页面标题大纲，区分内容主标题、导航/弹窗/页脚标题与隐藏控件。源 HTML 不等于最终可见页面。

- H1 表达本页主题，Title 负责搜索结果里的识别；二者不必逐字一致。优先形成清楚的主标题，不用“有多个 H1 必然受罚”解释修改。
- H2 按主要问题分段；H3 是当前 H2 的子问题。尽量避免无理由跳级，返回上层可以跨级。层级用于组织内容及辅助技术，不因字号决定标签。
- 给每个建议标题附一行“该段回答什么”，再补相应正文。关键词只在该标题真正对应主题时使用；不是每层都插一次主词。
- 级别调整与文案调整分开记录。相同“Specifications”多次出现时记录提取结果中的 `heading_index`（全部 H 标签一并计数，从 1 开始），回读实际 DOM/模块确认对象。
- 产品卡片可有自己的标题，是否占 H2/H3 取决于页面结构。不能为了工具计数把有效标题全部改为普通文本。

## 关键词怎样进入正文

围绕采购者完成任务组织内容：是什么/适用范围 → 如何比较/选择 → 规格与条件 → 可信依据 → 下一步询价。行业和页型不同，顺序及模块可不同，复用已确认架构。

| 位置 | 选择原则 |
| --- | --- |
| 开头 | 清楚说明产品/服务及适用任务；自然表达主主题，不限定前100字 |
| 比较/规格/选型段 | 辅助词必须对应真实内容；数字、单位、型号与条件同列 |
| 应用段 | 解释适用与限制，不能把不供货场景纳入业务承诺 |
| FAQ | 仅保留实际问题；不为重复关键词强凑数量 |
| CTA | 告诉采购者可提供什么资料、下一步获得什么；无依据不承诺回复时限 |
| 内链 | 给读者实际可用的下一页，锚文本准确简洁；不硬塞所有变体 |
| 图片 alt | 描述真实图像用途；不把每张图片变成关键词清单 |

关键词安排记录实际表达，区分原词、自然表达和不用的原因。词频可辅助发现机械重复，但无统一密度；统计不能替代语义审阅。主词缺少完整精确匹配不自动失败，术语自然变化也不能替换成错误型号或单位。

## 让内容比“覆盖关键词”更有用

逐模块回答三个问题：买家要作什么判断；现在能否找到答案；本企业有什么可公开核验的资料能帮助判断。用这些问题安排优先级，不把竞品所有章节或工具建议词都搬进来。

| 本页任务 | 适合补的内容 | 不能靠改稿补出来的事实 |
| --- | --- | --- |
| 从类目中选型号 | 真实产品入口、可比参数/条件、差异和选择说明 | 没有资料的型号、库存、价格和供货范围 |
| 核对具体型号 | 同口径尺寸/重量/配置、适配限制、图纸或资料入口 | 把系列极值、选配参数或其他机型数据写成标配 |
| 筛选制造商 | 实际身份、过程、能核验的检验/交付资料及资料请求方式 | 虚构自有工厂、认证、客户名单、产能或国家合规 |
| 解决技术/选型问题 | 先回答核心问题，再给比较标准、步骤、依据和适用条件 | 没有做过的测试、专家审核和亲历经验 |

保留页面已经解决得好的部分。对缺口决定“补可用事实 / 调整表达或顺序 / 交其他页 / 等待资料”，并说明理由。若新增内容只复述已有信息、与采购无关或缺乏可信依据，可以不加。

类目与型号页先让用户接触产品、规格和选择工具，信息文章先让用户取得核心答案；不要以长导语挤走主要功能。精确布局取决于既有设计，不能仅凭文本快照声称已检查首屏或移动端。表格、清单、图解、视频仅在更方便比较/理解时采用，不为搜索特征强行制造格式。

差异化优先来自已验证的型号差异、真实限制条件、可用图纸、采购清单、案例或测量方法，而非“专业、领先、优质”等空话。资料有出处不等于企业获证；引用外部技术资料须保留适用范围。本企业的原创资料与同行公开自述分开，未提供的资料列到正文外。

涉及经验/专业性时说明真实作者、审阅者或资料来源，以及必要的方法/条件；没有证据不补“工程师审核”或专家履历。不制作 E-E-A-T 分数，不以虚构作者或堆积资质替代可核内容。更新旧文时修正实际过期信息并记录变更，不只刷新年份。

内链同时考虑本页给读者的下一步和已有相关页面到本页的入口；目标应可用，锚文本说明目标任务，正常链接有可抓取的 href。不把所有相关词变成链接，也不批量改未经授权的页面。图片/图纸应靠近对应内容，必要时保留型号、单位或条件说明；看过实图再写 alt。技术可抓取性与真实页面效果分别验证。

## 完整改稿与回读

推荐交付顺序：本页目标 → Title/描述/H1 → 建议 H 大纲和实际正文 → 关键词安排 → 可定位改动 → 事实缺口 → 实施状态。

完整改稿不能只有检查清单。新稿与保留段落应能组合为清楚的一页；大段改写保留原文与实际替换范围，局部修改不重写其余内容。所有公司专属数字和承诺逐句核资料。

实施后检查最终页地址/型号、真实 document.title、description、各级标题和正文。模板/SEO 插件可能覆盖编辑值，需保存后重开并回读对应环境；手机预览检查标题断行和段落可读性。关键词计数或本地文件保存不证明线上生效。

## 示例（虚构教学情境）

假设：企业经确认销售新小型挖掘机；目标页是产品目录，主词 `mini excavators`。这个例子没有实际品牌、型号和数值。

- Title：`Mini Excavators: Models and Selection Guide | [Brand]`（仅当页面确实有型号目录和选型内容；品牌需替换）
- H1：`Mini Excavators`
- H2：`Compare Available Models` → 用已核型号与可比较参数展示选择。
- H2：`Choose a Machine for Your Worksite`
- H3：`Check Access Width and Operating Weight` → 给出条件说明和真实参数入口。
- H2：`Request Specifications and a Quote` → 列采购者应提供的用途、数量、交付市场等信息。

“mini digger”可在解释同类称呼的正文自然出现；不能为了覆盖 rental 把目录改成租赁服务。具体型号页的主词仍须由该型号身份和已选词决定。上述结构只是示意，不是所有挖掘机网站的固定模板。

## 依据
