# 这个品类的企业买家怎样找货

用于外贸 B2B 独立站的 SEO 标题及整页研究，覆盖首页、About Us、类目、详情和文章。用户给出页面或品类后，由 Codex 调研并推荐。已有资料可直接沿用，用户无需先挑 `custom`、`factory` 或其他词。

## 先从用户词库提词，再用 Google 找同行并实读页面

1. 从本页分组取产品词和相关成员，沿架构确认产品范围、相邻页和可比的竞品集合或单款地址。用具体地址取回排名表里的词，再用产品别称、材料、工艺和采购方式扫总库。来源和归属分开保留。
2. 按本页产品或服务设计多条自然的 B 端查询。小挖集合页可分搜 `mini excavator manufacturer`、`mini excavator factory`，定制加工服务可搜 `precision CNC machined parts manufacturer`。用目标市场语言和企业实际供货方式选组合，英文“制造商”用 `manufacturer`。采购词零量或缺数也值得核实。
3. 入选对象须是可比的外贸 B2B 独立站。在自有站核对业务、跨境供货或企业采购依据，例如品牌客户、批量生产、出口市场与询价。兼营零售和批发只取明确的 B2B 页。零售 B2C、平台、目录、社交和榜单留作筛选记录。可以读到原始第 6 位甚至更靠后，换查询或复用架构认可的同行。同一家公司的多个页面只计一家。可先以约五家合格同行作对照，只有三家适配就记录这三家及查找范围，有必要时继续往后找。
4. 搜索命中的 URL、实读页面的 URL、客户表中实际排名 URL 分列。Aikusu 的工厂首页可用来发现其 OEM 手机壳集合页，后者的 Title 有 OEM 与 wholesale，H1 为 `Phone Case`，导语补 ODM 与研发能力。以集合页 URL 查它自己的排名词。[同行首页](https://www.aikusu.com/) · [OEM 手机壳集合页](https://www.aikusu.com/phone-case.html)
5. 逐项读 HTML Title、主要 H1、首屏可见副标题或导语以及正文 H2。保留原短语、实际标签和用途。副标题也可能是 H2、p 或 div，同一句只算一处。型号卡、筛选栏、促销与导航单列。缺项记“未见”，未读到记“未核”。服务页可从 Norck 的材料、公差分节学习落点，再由客户自己的能力决定改稿。[CNC 加工服务页](https://www.norck.com/collections/cnc-machining)
6. 把同行标题新发现的表达和该 URL 的排名词分别记来源，再与原分组、原稿及业务资料核对。同义变体可共用一句。确认哪些新增意图真正改变本页文案。

## 读完整采购短语

先读库内整条查询及其排名 URL，再看单词。找出产品或供应方这个中心词，读清其余词修饰什么、共同描述哪一种订单。在现有选词理由里记下影响落点的区别，保留原行供回查。下面用三条虚构词库记录举例。

| 原始查询 | 买家在找什么 | 决定能否写进本页的企业事实 |
| --- | --- | --- |
| `custom workwear manufacturer` | 买家找能按要求生产工装的制造商。`custom` 指服装可定制，`manufacturer` 指供方身份。 | 核谁生产以及接受哪些定制。为成衣加标的经销商只写实际服务。 |
| `factory direct workwear` | 买家希望直接向生产方订货。`direct` 说的是交易渠道。 | 核买家能否与生产方直接下单。仅有车间照片或自产资料还缺接单依据。 |
| `wholesale blank workwear` | 买家要按批发条件买未加标的工装。`blank` 描述交付的衣服，`wholesale` 描述交易。 | 核是否可按批发条件交付空白款。是否现货、是否可另外刺绣各需资料。 |

同一家企业可能接受上述几种订单。只有这一个 URL 能承接同一张订单的条件，才适合自然合写。若空白款与刺绣款分属两个目录，按各自采购任务落词。若某款可以空白批发并选配刺绣，写清基础交付和可选项。新组合可以由编辑提出，分别保留支持各项含义的原词、同行实页和本企业资料，不把新组合记作词库原句。

## 如何查候选词

[英文采购用词表](b2b-buying-modifiers.csv)每行给一个表达、中文适用条件、英文搭配示例和来源性质。按“词组”筛选当前行业，也可以直接搜索品类或采购动作。选择多少组由订单决定。需要查来源时读该行的公开网址。

| 用途 | 适合检索的词组 | 对标题的作用 |
| --- | --- | --- |
| 采购属性 | 供方身份与生产场所、供货渠道与买家、按需定制与订单驱动、品牌归属与委托制造、数量规模与生产阶段 | 研究找谁供货、谁负责设计、买多少和怎样生产。例如同一品牌订单可能同时支持 `custom` 与 `manufacturer`。 |
| 行业采购用语 | 服装面料与工艺标识、包装印刷与灌装、金属塑胶与按图加工、电子装配与元件交货、工程配套与设备交付、备件替换与项目选型 | 寻找买家在该行业实际用的词。工艺、商用场景或规格须与目标查询一同判断，部分词也用于零售。 |
| 采购条件 | 报价门槛与样品、备货物流与长期供货、规格适配与验收资料 | 可以区分采购任务。通常细节放摘要、参数、交易条件或询价入口；买家主要就搜这个条件时，才考虑放标题。 |

“来源用语”表示在所链原页核到了词或列出的相应写法，包含大小写、单复数、连字符等常见变化。“编辑扩展”是待验证的检索种子。英文搭配均为编辑示意。具体客户的搜索量、排名、业务资格和标题资格须按本次资料判断。将实测新词放回本项目选词记录，保留原语言、市场和证据。

## 五种页面怎样落词

| 页面 | 先判断 | 示例取舍（假设相关事实成立） |
| --- | --- | --- |
| 首页 | 买家在找哪种供应方？该身份能代表主营产品吗？ | 自营服装厂可比较当地的 `garment factory` 与 `clothing manufacturer`。多供应商选品的企业可查 `sourcing agent` 或 `supplier`。写产地前核实际生产地。 |
| About Us | 企业以什么身份供货，客户如何核实？ | 手机壳厂可在首屏说明面向品牌制造，在相关 H2 展示已核实的工序、厂址与服务市场。具体壳型由集合或详情承接。 |
| 产品类目页 | 买的是定制系列、批发成品、品牌代工、项目服务还是标准件？ | 按客户尺寸印刷邮寄盒可研究 `custom printed mailer boxes`。同一品类若只按整箱供应标准现货，应研究 `stock mailer boxes`、`mailer boxes in bulk` 等。先核该条件是否覆盖整类。 |
| 产品详情页 | 采购员凭什么认出这一款？这个型号能选哪些配置或交货形式？ | 轴承保留料号和品类，在 Title 与 H1 各自写明适用于这款的真实供货方式。若标签卷的核心订单是按图印刷且这款支持，可写 `custom printed` 和对应标签材质。 |
| 文章或指南 | 读者在这里解决哪个具体采购问题？ | 手机壳选材文章可在 H2 比较 TPU 和 PC 的选样条件，并从相关段落链接定制集合页。厂名或批发词用在能解释供货差异的地方。 |

同词也会改变采购方角色。`factory` 在 `factory automation` 里指设备使用场景，在找服装工厂的查询里指供应方。`OEM` 在电子代工中可描述合作方式，在替换件里可能意味着原厂来源。`custom T-shirts` 可能对应个人印一件或品牌来样生产，需读本市场实际结果。`wholesale` 要核批发交易，`bulk` 要区分数量和散装交付。候选只适合能力页、经销商招募页或资料下载时，记下去向。

## 记录到已有交付

用户要判断不同页面分别适合哪些词时，在现有改稿说明中列「页型、库内原词、同行实见用词与页面链接、本企业适用条件、建议放置位置」。同一域名的多个产品共用模板时，按一家同行计。只交一个页面标题时，给推荐标题，并用最能解释这次选词的库内原词和同页型实页简述理由。

局部改标题先给推荐 Title，再用一句话点出最能解释选词的规划、原词或业务依据。完整任务将库内原始查询与补充查询记入 `research.keyword_decisions`，用 `origin` 区分词库、同行或搜索实见、编辑假设和本站 GSC，用 `reason` 写明属性和取舍，`evidence_refs` 指到原行或实际观察。库内无匹配时在 `brief.angle` 或限制里记录查找范围，避免伪造一行库内命中。最终决定写入 `brief.angle`，实际落点写入 `keyword_placement`。沿用[研究数据约定](research-contract.md)。首页、集合页和详情页只有两处标题都满足品类与采购属性要求才记为通过。事实尚缺时可保留原文作草稿，公开实施标待核。[两处标题的检查](commercial-page-workflow.md)
